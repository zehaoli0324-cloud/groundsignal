# 生物医药 Benchmark 投资版图

更新时间：2026-10-13

本文件夹整理国内外生物医药 benchmark 的机构归属、子领域分类和经济价值证据，服务于 GroundSignal 的企业、产业链和投资研究。

## 文件

- `biomedical_benchmark_investor_memo_7p.pdf`：7 页投资人版概览。
- `organization_entity.csv`：归一化机构实体、机构类型、地区和角色。
- `benchmark_subcategory_mapping.csv`：45 个 benchmark 的一级领域和二级子领域映射。
- `benchmark_economic_value_evidence.csv`：买方、价值链、商业信号、证据等级和潜在价值分数。
- `benchmark_registry.csv`：benchmark 官网、论文、代码和数据入口。
- `benchmark_assessment.csv`：题目量、质量、难度、SOTA 压力和经济相关性初评。
- `benchmark_organization.csv`：benchmark 的主办/维护组织归属。
- `ORGANIZATION_SUBCATEGORY_VALUE_PLAN.md`：机构、子领域和经济价值的完整整理方法。
- `ORGANIZATION_CLASSIFICATION.md`：按公司、高校、研究机构和社区的组织分类。
- `PARALLEL_BIOMEDICINE_CLASSIFICATION.md`：遗传学图谱之外的医学题目分类说明。

## 口径

- 当前样本包含 45 个 benchmark 和 39 个归一化机构实体。
- 经济价值分数是潜在价值优先级，不是收入、估值或市场规模。
- 当前公开资料中没有系统披露 benchmark 级别的采购金额、客户数量或授权收入；商业证据需要继续核验。
- 原始大体量题库和中间压缩包不放入本目录，避免把不必要的大文件写入企业情报仓库。
