GroundSignal 企业情报采集 · Windows x64 测试版 0.3.0-beta

开始使用
1. 完整解压 ZIP，保留 GroundSignal.exe 和 _internal 文件夹在一起。
2. 双击 GroundSignal.exe，默认浏览器会自动打开本机界面。
3. 点击“连接 Obsidian”，选择已发现的笔记库，或点击“选择文件夹”。
4. 点击“连接并保存”。看到“已连接 Obsidian”后输入公司名称，点击“搜索并保存”。
5. 完成后点击“在 Obsidian 中打开”，查看笔记和来源。

无需安装 Python，也无需填写 API key。需要安装 Obsidian 桌面版并先创建一个笔记库。
Obsidian 官方下载：https://obsidian.md/download
选择的是笔记库本身，不是上一级目录；程序会检查 .obsidian 配置和写入权限。

这是“本地应用 + 浏览器界面”的便携测试版，不是安装程序。
应用只监听本机 127.0.0.1，不提供互联网访问。
界面底部“退出采集服务”可关闭后台；只关浏览器页面不会结束后台程序。
重复双击会打开已运行的同版本应用。更新版本前先退出旧应用。

数据在哪里
笔记直接保存在你自己选择的 Obsidian 笔记库中。
应用设置、搜索缓存及启动错误日志：%LOCALAPPDATA%\GroundSignal
发行包不包含开发者的笔记库、路径配置、搜索缓存或密钥。
删除应用文件夹不会删除你的笔记。断开连接也不会删除笔记。

测试时注意
公开搜索源可能限流，程序会切换备用源并显示原因；不保证所有网站始终可访问。
搜索会向搜索服务发送你输入的公司名，并读取公开来源网页。
采集结果是待核实线索，不等于事实验证，不自动认定投资或供应关系。
此内部测试包未做代码签名；若组织的安全策略阻止运行，请联系管理员，不要关闭安全软件。

反馈时请提供
应用版本、Windows 版本、搜索的公司名、错误提示截图。
若无法启动，可提供 %LOCALAPPDATA%\GroundSignal\collector-startup-error.log。
不要提交整个笔记库或任何 API 密钥。


批量更新公司资料
连接笔记库后，点击“更新全部公司”或“更新指定公司”。全部范围是 01-公司 文件夹下的公司笔记（不含子目录）。指定更新支持名称筛选、多选。更新会重新搜索并刷新自动采集区，保留手工内容与历史来源记录，不会自动把待核实信息变成已核实。
任务逐家处理，显示成功/失败结果；失败后可点击“重试失败项”。点击“停止剩余更新”后会先完成当前公司。请保持服务运行，队列不支持退出后恢复。搜索限速和冷却仍有效，失败时已有笔记不因搜索失败而删除。
